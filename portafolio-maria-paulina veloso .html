Alke Wallet

Caso de estudio

Una billetera digital simulada, construida desde cero con HTML, CSS y JavaScript, sin frameworks.

Descripción

Aplicación web que simula una billetera digital: permite registrar usuarios, visualizar el saldo disponible y llevar un registro de transacciones (envíos y recepciones de dinero simuladas).

Desafío principal

Estructurar la lógica de una billetera —manejo de saldo y transacciones— sin un framework, validando los formularios y manteniendo los datos consistentes en pantalla en todo momento.

Solución propuesta

JavaScript vanilla para validar formularios en tiempo real, actualizar el DOM ante cada transacción y organizar los datos separando claramente la lógica de la presentación.

Herramientas utilizadas

HTML5, CSS3 y JavaScript, con control de versiones en Git.

Principales aprendizajes

Manipulación del DOM, validación de formularios, manejo de eventos, organización del código en funciones reutilizables y diseño de interfaces responsivas.

Métricas de impacto

3funcionalidades completas: registro, transacciones e historial
↓errores de validación tras rondas de testing manual
↑tiempos de carga al optimizar el código JavaScript

Por qué elegí este proyecto

Porque implicó resolver un problema de lógica de negocio real —el manejo de dinero y transacciones— sin depender de un framework, lo que demuestra que mis fundamentos de programación son sólidos y transferibles a cualquier stack tecnológico.
